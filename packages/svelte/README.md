# `@monigarr/meg-svelte`

Svelte components for MEG glyphs (`currentColor`).

```bash
pnpm add @monigarr/meg-svelte
```

```svelte
<script>
  import { AuthorityMark, MegIcon } from "@monigarr/meg-svelte";
</script>

<AuthorityMark size={24} />
<MegIcon name="governance" title="Governance" />
```

See [getting started](../../docs/getting-started.md) and the [style guide](../../docs/style-guide.md).
