# `@monigarr/meg-font`

**MEG-Glyphs** icon font (TTF, WOFF, WOFF2, CSS) with Private Use Area mapping.

## Install

```bash
pnpm add @monigarr/meg-font
```

Import CSS in a web app:

```ts
import "@monigarr/meg-font/css";
```

Or install `MEG-Glyphs.ttf` system-wide for VS Code / desktop apps.

## Stable codepoints

| Shortcode | Codepoint |
|-----------|-----------|
| `:authority:` | U+E001 |
| `:certitude:` | U+E002 |

Full map: packaged `unicode-map.json` (resolved) and repo [`config/unicode-map.json`](../../config/unicode-map.json).
