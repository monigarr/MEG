# `@monigarr/meg-vue`

Vue 3 components for MEG glyphs (`currentColor`).

```bash
pnpm add @monigarr/meg-vue
```

```vue
<script setup>
import { AuthorityMark, MegIcon } from "@monigarr/meg-vue";
</script>

<template>
  <AuthorityMark :size="24" />
  <MegIcon name="human_judgement" title="Needs human judgement" />
</template>
```

See [getting started](../../docs/getting-started.md) and the [style guide](../../docs/style-guide.md).
