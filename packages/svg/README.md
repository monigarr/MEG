# `@monigarr/meg-svg`

Optimized MEG SVG sources plus `glyphs.json` catalog.

```bash
pnpm add @monigarr/meg-svg
```

```ts
import { glyphs } from "@monigarr/meg-svg";
// or: import catalog from "@monigarr/meg-svg/glyphs.json"
```

Individual files: `@monigarr/meg-svg/<id>.svg` (see package exports).
