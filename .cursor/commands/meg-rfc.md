description: Draft a glyph or standards RFC per MEGS-0007
---

Draft a contribution RFC following `docs/megs/MEGS-0007-contribution-and-rfc.md`.

1. Ask for missing inputs only if needed: proposed `id`, category, meanings, breaking vs additive.
2. Produce an RFC markdown draft covering proposal, validation plan, review plan, codepoint policy, and landing checklist.
3. If a new glyph is in scope, point to `/meg-new-glyph` for implementation after RFC approval.
4. Do not merge or assign codepoints unless the user asks to implement.
