# MEGS-0008: Originality and Brand

| Field | Value |
|-------|-------|
| Status | Draft |
| Version | 0.1.0 |
| Normative | Yes (when Approved) |

## 1. Purpose

Protect MEG as an original MoniGarr Engineering communication system and define brand posture for the glyph language.

## 2. Originality mandate

- Every glyph, semantic definition, and implementation MUST be original work designed for MoniGarr Engineering.
- Contributors MUST NOT imitate or reproduce geometries from Lucide, Heroicons, Font Awesome, Bootstrap Icons, Material Icons, Fluent, Carbon, or other icon libraries.
- Quality references (Adobe, IBM Carbon, Material, Fluent, Primer, Noto, VS Code, Figma community best practices) are **aspirational bars for craft**, not sources to copy.

## 3. Engineering philosophy (verbatim)

MoniGarr Engineering philosophy for this project:

- Engineering is communication.
- Specifications are contracts.
- Architecture is language.
- Governance enables innovation.
- Human judgment remains essential.
- AI amplifies expertise rather than replacing it.
- Trust is engineered.
- Quality compounds.
- Design communicates intent.
- Language shapes systems.

## 4. Brand posture

- MEG communicates **engineering intent**, not decorative ornament.
- Visual language SHOULD feel durable, calm, and enterprise-ready.
- Brand assets (logo, social images, presentation templates) MUST stay consistent with glyph stroke language when introduced.

## 5. Licensing and attribution

- Code and font licensing are tracked in repository license files (`LICENSE-CODE.md`, `LICENSE-FONT.md`, `OFL.txt`) and MUST be completed before public release packaging.
- Downstream attribution requirements MUST be documented once licenses are chosen.
- Until licenses are filled, treat assets as unpublished draft material for this repository.

## 6. Agent obligation

Agents MUST refuse requests to “copy”, “port”, or “recreate” third-party icon sets into MEG. Instead, redesign from engineering intent under MEGS-0001 and MEGS-0002.
