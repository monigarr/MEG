# Security Policy

## Supported versions

Security fixes are applied to the latest released `v*.*.*` tag on the default branch.

## Reporting a vulnerability

Please report security issues privately to **MoniGarr Engineering** via the repository’s GitHub Security Advisories (preferred) or by contacting the maintainers through the organization profile.

Do not open public issues for undisclosed vulnerabilities.

We will acknowledge receipt within 7 days and provide a remediation timeline after triage.
